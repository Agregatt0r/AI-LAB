# 02-ml: Machine Learning Algorithms from Scratch

This directory contains practical implementations, mathematical foundations, and intuitive explanations of core Machine Learning algorithms implemented from scratch in Python and NumPy.

Each topic builds directly on the mathematical principles explored in `01-math` (linear algebra, calculus, probability, and statistics).

---

## 🗺️ Roadmap & Modules

| # | Module | Core Focus | Why it matters |
|---|---|---|---|
| 1 | **[Linear Regression](linear-regression/README.md)** | Supervised Learning for continuous targets | The foundational regression model: hypothesis, MSE, gradient descent, vectorization, multi-variable modeling, the Normal Equation, and regularization. |

---

## 📂 Structure

Each algorithm folder is organized into focused submodules, each containing:
- `README.md`: Mathematical theory, intuition, geometric interpretation, and formulas.
- `practice.py`: Hands-on Python and NumPy implementations from first principles without black-box machine learning libraries.
