# Power Rule

The **power rule** is a fundamental formula for finding the derivative of any power function $x^n$.

## Formulas

1. **Constant Rule:**
   $$\frac{d}{dx}[c] = 0$$

2. **Power Rule:**
   $$\frac{d}{dx}[x^n] = n x^{n-1}$$

3. **Constant Multiple Rule:**
   $$\frac{d}{dx}[c \cdot x^n] = c \cdot n x^{n-1}$$

## Examples

- $f(x) = x^4 \implies f'(x) = 4x^3$
- $f(x) = 3x^2 \implies f'(x) = 3 \cdot 2x = 6x$
- $f(x) = 5x^3 + 2x \implies f'(x) = 5(3x^2) + 2(1) = 15x^2 + 2$
- $f(x) = 7 \implies f'(x) = 0$
