# Sum and Difference Rule

The derivative of a sum or difference of two or more functions is equal to the sum or difference of their derivatives (**linearity of derivatives**).

## Formula

$$\frac{d}{dx}[f(x) \pm g(x)] = f'(x) \pm g'(x)$$

For a polynomial:
$$P(x) = a_n x^n + a_{n-1} x^{n-1} + \dots + a_1 x + a_0$$
$$P'(x) = n a_n x^{n-1} + (n-1) a_{n-1} x^{n-2} + \dots + a_1$$

## Examples

1. **$f(x) = 4x^4 - 3x^2 + 7x$**
   $$f'(x) = 4(4x^3) - 3(2x) + 7(1) = 16x^3 - 6x + 7$$

2. **$f(x) = x^3 + 5x^2$**
   $$f'(x) = 3x^2 + 10x$$

3. **$f(x) = x^5 + 2x^3 - 8$**
   $$f'(x) = 5x^4 + 6x^2$$
