# Calculus

**Calculus** is the mathematical study of continuous change. In Machine Learning, calculus (specifically derivatives, partial derivatives, the chain rule, and gradients) provides the mathematical foundation for optimizing models via **Gradient Descent** and **Backpropagation**.

This folder is practice + notes for the core calculus concepts used in linear/logistic regression, optimization, and neural networks.

Each subfolder has:
- `README.md` — theory for that topic
- `practice.py` — your exercises

## Structure

```
calculus/
├── derivative              what a derivative is (rate of change, slope of tangent line)
├── power-rule              power rule d/dx (x^n) = n*x^(n-1) and constant rule
├── sum-rule                sum and difference rules for polynomials
├── partial-derivatives     derivatives with respect to one variable, holding others constant
├── chain-rule              composite function derivative (foundation of backpropagation)
└── gradient                vector of partial derivatives (foundation of gradient descent)
```
