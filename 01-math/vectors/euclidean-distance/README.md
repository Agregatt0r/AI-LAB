# Euclidean distance

The straight-line distance between two points in a plane or higher-dimensional space.

```
A = [1, 2]
B = [4, 6]

d(A, B) = sqrt((a1 - b1) ** 2 + (a2 - b2) ** 2) = 5
```

Magnitude is the length of a vector from the origin to its tip.
Euclidean distance is the length of the vector `A - B` (distance between two points).
