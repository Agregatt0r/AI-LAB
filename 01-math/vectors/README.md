# Vectors

A **vector** is an ordered collection of numbers. In ML it is usually a list of features
(height, width, pixel values, embeddings, etc.).

This folder is practice + notes for the basic vector operations used later in linear
algebra, linear/logistic regression, and neural networks.

Each subfolder has:
- `README.md` — theory for that topic
- `practice.py` / `practice.txt` — your exercises

## Structure

```
vectors/
├── vector                  what a vector (and a scalar) is
├── addition                add two vectors component-wise
├── scalar-multiplication   scale every component by one number
├── dot-product             multiply corresponding components, then sum → 1 number
├── magnitude               length of a vector
└── euclidean-distance      straight-line distance between two points
```
