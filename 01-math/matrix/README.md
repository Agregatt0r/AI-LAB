# Matrices

A **matrix** is a rectangular grid of numbers arranged in rows and columns.

This folder is practice + notes for the basic matrix operations used later in linear
algebra, linear/logistic regression, and neural networks.

Each subfolder has:
- `README.md` — theory for that topic
- `practice.py` / `practice.txt` — your exercises

## Structure

```
matrix/
├── matrix                  what a matrix is (shape, indexing, ML view)
├── addition                add two matrices element-wise
├── scalar-multiplication   scale every element by one number
├── matrix-multiplication   multiply two matrices (row · column)
├── transpose               swap rows and columns
├── matrix-vector           multiply a matrix by a vector
└── inverse                 determinant, identity, and inverse
```
